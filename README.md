# QQ家园怀旧平台 - QQ Games

一个复刻经典WAP手机QQ家园的怀旧游戏平台，包含多款当年的经典文字游戏。

## 功能特性

### 🏠 家园底座系统
- 用户账号/个人资料/个性设置
- 个人主页、来访记录、留言板
- 好友系统（添加/申请/黑名单/分组）
- 家族系统（创建/加入/签到/聊天/成员管理）
- 论坛系统（版块/发帖/回复/置顶/精华）
- 公共聊天室 + 家族聊天室
- 同城系统（城市动态）
- 图标点亮系统
- 成就系统
- 消息通知中心
- 排行榜

### 💰 公共经济系统
- 多货币钱包（G币/金币/元宝/银两）
- 货币流水记录
- 公共背包（按模块分类）
- 商城系统（按模块分类商品）
- 活动系统
- 系统公告

### 🎮 游戏模块

#### ⚔️ 精武堂
- 修炼系统（挂机获经验）
- 比武切磋（PVP对战）
- 帮派系统
- 转职系统（神/魔/仙）
- 装备系统（武器/防具/饰品）
- 强化/镶嵌/武魂/法宝
- 三国副本

#### 🌸 魔法花园
- 种花、浇水、除草、除虫
- 花朵合成系统
- 花谱点亮收集
- 好友送花/偷花

#### 🌾 阳光牧场
- 种植作物（小麦/白菜/胡萝卜/玉米/草莓等）
- 养殖动物（鸡/鸭/奶牛）
- 浇水/施肥/除虫/收获
- 好友互动（偷菜/帮忙）

#### 🍳 美味小镇
- 经营餐厅
- 学习菜谱（多菜系）
- 雇佣好友服务员
- 添油、翻橱柜、放蟑螂
- 星级升级系统

#### ⛵ 纵横四海
- 大航海时代背景
- 城市探索（泉州/杭州/广州/扬州/里斯本等）
- 航线航行（随机事件：海盗/风暴/宝箱/奇遇）
- 任务系统（主线/支线）
- 回合制海战
- 装备系统（武器/铠甲/头盔/战靴/戒指/项链）
- 宠物/坐骑/羽翼/随从系统
- 宝石/卡片/圣痕强化
- 山寨系统（农场/练功房）
- 贸易系统

#### 🐉 召唤之王
- 捕捉幻兽、养成对战
- 4大地图（新手村/清风森林/烈焰峡谷/幽冥深渊）
- 12种幻兽（史莱姆/月光兔/灵猫/苍狼/炎龙/幽灵/暗影龙/深渊魔王等）
- 3种捕捉球（普球/强力球/超级球）
- 幻兽技能系统
- 战骨系统（7部位：头骨/胸骨/臂骨/腿骨/手骨/尾骨/元魂）
- 魔魂系统（6品质：废/黄/玄/地/天/神）
- 战灵系统（水/土/火/木/金/神）
- 擂台PVP
- 战场系统（猛虎战场/飞鹤战场）
- 联盟系统
- 师徒系统

## 技术栈

- **后端**: FastAPI + SQLAlchemy + SQLite
- **前端**: Jinja2 模板 + WAP风格CSS
- **认证**: JWT + bcrypt
- **部署**: Uvicorn

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行服务器
```bash
python main.py
```

访问 http://localhost:8000

### 默认账号
- 管理员: `admin` / `admin123`

│   └── summon_king.py    # 召唤之王
├── templates/             # HTML模板
│   ├── base_wap.html     # WAP基础模板
│   ├── home/             # 家园页面
│   ├── jingwutang/       # 精武堂页面
│   ├── sunny_farm/       # 阳光牧场页面

├── static/               # 静态资源
│   └── css/style.css     # WAP风格样式
└── utils/                # 工具函数
